# sql-data-warehouse-project
Building a modern data warehouse with SQL server, including ETL processes, data modeling and analytics.
Welcome to Data warehouse and Analytics Project repository.
This projects demonstrates a comprehensive data warehouse an analytics solution, from building data warehouse to finding actionable insights. Highlights industry best practices in Data Engineering and Data Analytics.

### BI: Analytics and Reporting (Data Analytics):-
    OBJECTIVE:- Develop SQL Based analytics to deliver detailed insights info.
